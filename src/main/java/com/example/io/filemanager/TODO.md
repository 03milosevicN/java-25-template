## Rad sa `File` klasom
| Metoda | Opis |
| --- | --- |
| `exists()` | Proverava da li putanja postoji. |
| `createNewFile()` | Kreira novu praznu datoteku. |
| `mkdir()` | Kreira direktorijum. |
| `mkdirs()` | Rekurzivno kreira direktorijum i sve potrebne nadređene direktorijume. |
| `delete()` | Pokušava da obriše datoteku ili direktorijum. |
| `renameTo()` | Pokušava da promeni naziv datoteke ili direktorijuma. |
| `listFiles()` | Vraća listu datoteka i direktorijuma unutar direktorijuma. |
| `isFile()` | Proverava da li putanja predstavlja datoteku. |
| `isDirectory()` | Proverava da li putanja predstavlja direktorijum. |
| `length()` | Vraća veličinu datoteke izraženu u bajtovima. |
| `getAbsolutePath()` | Vraća apsolutnu putanju do datoteke ili direktorijuma. |
